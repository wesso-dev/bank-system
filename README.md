# 🏦 نظام إدارة خدمات البنك (Bank Management System)

تطبيق بلغة **C** لإدارة طابور العملاء والعمليات البنكية باستخدام هياكل البيانات المتقدمة (**Queue** و **Stack**) مع ميزة الحفظ الدائم في الملفات (**File Persistence**).

---

## 🛠️ هياكل البيانات والتقنيات المستخدمة (Data Structures & Architecture)

1. **الطابور (Queue - FIFO 🎟️):**
   * ينظم دور العملاء في البنك حسب الأسبقية ("من يأتي أولاً يُخدم أولاً").
2. **المكدس (Stack - LIFO 🥞):**
   * يسجل العمليات المكتملة لدعم خاصية **التراجع (Undo)** عن آخر خدمة.
3. **التخزين والبحث الخطي (Files & Linear Search 📁):**
   * حفظ بيانات العملاء في ملف نصي (`customers.txt`).
   * البحث الخطي برقم الـ ID (`==`) أو بالاسم باستخدام `strcmp()`.

---

## 💡 القرارات البرمجية والتحسينات (Optimization & Memory Management)

* 🔄 **دمج السحب والإرجاع (Node Reuse):**
  * تُرجع دوال `pop()` و `dequeue()` مؤشراً على العقدة المحددة (`Node*`) بدلاً من مسحها، مما يسمح بنقل العقدة مباشرة بين الطابور والمكدس دون إعادة حجز ذاكرة جديدة بـ `malloc()`، وهذا يوفر العمليات الحسابية ويمنع استهلاك الذاكرة.

* 🧹 **الوقاية من تسريب الذاكرة (Memory Leak Prevention):**
  * تم وضع حد أقصى لحجم المكدس ($20$ عنصراً). عند تجاوز هذا الحد، يقوم النظام تلقائياً بتنظيف تحرير ذاكرة أقدم عقدة في القاع عبر `free()` لإبقاء استهلاك الذاكرة مثالياً.
